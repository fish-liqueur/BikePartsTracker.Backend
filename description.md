### Project Description

We need to create a backend app, a bicycle parts tracker.
We will use Strava API to get information about User's bikes and rides. 
We will also have another entity, a bike part. It will have a maintenance scheduling rules. This information we will store. Combined by strava data we will calculate bike parts usage and notify User by frotnend (we will have api for frontend app).


### Technologies
- .Net
- PostgreSQL
